# Web Development Practice Repository

This repository contains my original HTML and CSS practice work completed throughout 2024 while learning web development through the book **HTML & CSS by Jon Duckett**.

The folders in this repository follow the chapter structure from the book and contain the example code, exercises, and personal modifications I completed while working through the material.

## Purpose

The goal of this repository was to:

* Learn HTML fundamentals
* Learn CSS fundamentals
* Practice building web pages from scratch
* Understand how websites are structured and styled
* Build a strong foundation before moving into more advanced topics
